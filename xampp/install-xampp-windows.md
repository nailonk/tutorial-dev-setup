# Instalasi Xampp di Windows

## Unduh XAMPP
Unduh dari [Website Resmi Apache Friends](https://www.apachefriends.org/download.html)


Pilih **XAMPP for Windows**

---

## Instalasi XAMPP

- Jalankan file installer XAMPP yang telah diunduh.
- Jika muncul peringatan **User Account Control (UAC)**, pilih **Yes**.
- Pada halaman pemilihan komponen, pastikan pengaturan sesuai dengan gambar berikut.
![config](https://github.com/nailonk/tutorial-dev-setup/blob/main/asset/config-xampp.png)

- Klik **Next** untuk melanjutkan.
- Gunakan lokasi instalasi default: **C:\xampp**
- Klik **Next** dan tunggu proses instalasi hingga selesai.
![install](https://github.com/nailonk/tutorial-dev-setup/blob/main/asset/install-xampp.png)
- Klik **Finish** untuk menyelesaikan instalasi.

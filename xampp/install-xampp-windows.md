# Instalasi Xampp di Windows

## Unduh XAMPP
Unduh dari web resmi Apache Friends:
[Website Resmi Apache Friends](https://www.apachefriends.org/download.html)


Pilih **XAMPP for Windows**

---

## Instalasi XAMPP

1. Jalankan file installer XAMPP yang telah diunduh.
2. Jika muncul peringatan **User Account Control (UAC)**, pilih **Yes**.
3. Pada halaman pemilihan komponen, pastikan pengaturan sesuai dengan gambar berikut.
4. Klik **Next** untuk melanjutkan.
5. Gunakan lokasi instalasi default: **C:\xampp**
6.  Klik **Next** dan tunggu proses instalasi hingga selesai.
7. Klik **Finish** untuk menyelesaikan instalasi.

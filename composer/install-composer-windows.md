# Tutorial Install Composer di Windows untuk Pemula 
## Requirements
- PHP sudah terinstal (versi 7.4 ke atas). Cek dengan menjalankan di terminal
```
php -v
```
> Jika belum ada silahkan kunjungi tutorial [berikut](https://github.com/nailonk/tutorial-dev-setup/blob/main/xampp/install-xampp-windows.md)
- Microsoft Visual C++ Redistributable sudah terinstal
---

## Instalasi Composer
- Unduh dari [situs resmi Composer](https://getcomposer.org/download/)
- Pilih **Composer-Setup.exe** dan unduh
- Klik dua kali file `Composer-Setup.exe`
- Pilih **PHP path** jika diminta (biasanya otomatis terdeteksi)
  ![](https://github.com/nailonk/tutorial-dev-setup/blob/main/asset/path.png)
  > Centang opsi **Add this PHP to your path** agar bisa dijalankan dari Command Prompt  
- Klik **Install** dan tunggu proses selesai
  ![](https://github.com/nailonk/tutorial-dev-setup/blob/main/asset/install-composer.png)
